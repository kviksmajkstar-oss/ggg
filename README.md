# NOMERCY

NOMERCY — это современный фронтенд-прототип социальной сети, созданной **Русланом Kviksmajk** — музыкантом, автором **kviksmajkmusic** и разработчиком проекта NOMERCY.

## Что работает сейчас

- рабочие вкладки: **Лента**, **Live**, **Games**, **Chats**, **Profiles**;
- светлая и тёмная тема через переключатель в шапке;
- кастомизация активного профиля через **Profile Lab**;
- интерактивная лента с публикацией постов, фильтрами и лайками;
- рабочие чаты с переключением диалогов, отправкой сообщений, быстрыми репликами, typing-индикатором и автоответами;
- демонстрация онлайн-общения прямо в интерфейсе NOMERCY;
- рабочие профили с spotlight-блоком и возможностью сделать профиль активным;
- встроенные мини-игры `Tap Rush` и `Color Match`;
- сохранение ключевого состояния интерфейса в браузере через `localStorage`.

## Локальный запуск

Открой `index.html` в браузере

или запусти локальный сервер:

```bash
python3 -m http.server 8000
```

После этого открой `http://localhost:8000`.
