# NOMERCY

NOMERCY — это уже не просто статичный макет, а **реально работающий локальный сайт соцсети** с backend на Python и базой SQLite.

## Что работает

- регистрация и вход пользователей;
- хранение аккаунтов в SQLite;
- редактирование профиля;
- публикация постов в ленту;
- лайки на постах;
- список пользователей;
- личные сообщения между пользователями;
- светлая и тёмная тема интерфейса.

## Технологии

- Python 3
- `http.server` + `sqlite3`
- HTML / CSS / JavaScript без внешних фреймворков

## Запуск

```bash
python3 server.py
```

После запуска открой:

```text
http://127.0.0.1:8000
```
