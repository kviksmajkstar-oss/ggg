# NOMERCY

NOMERCY — это реально работающий локальный сайт соцсети, который теперь запускается **без Python**, работает на разных устройствах в одной сети и не содержит тестовых аккаунтов по умолчанию.

## Что работает

- регистрация только реальных пользователей;
- защищённый вход по логину и паролю;
- редактирование профиля;
- смена аватарки;
- публикация постов в ленту;
- лайки на постах;
- список пользователей;
- личные сообщения между пользователями;
- светлая и тёмная тема интерфейса;
- запуск на разных устройствах в одной сети через `0.0.0.0`.

## Технологии

- Node.js без внешних зависимостей;
- встроенный HTTP-сервер;
- JSON-хранилище для локальных данных;
- HTML / CSS / JavaScript без фреймворков.

## Запуск

### Вариант 1 — через Node.js

```bash
node server.js
```

### Вариант 2 — через npm

```bash
npm start
```

### Вариант 3 — Windows

Запусти файл `start-nomercy.bat`.

Он:

- проверит, установлен ли `Node.js`;
- попробует открыть входящий доступ к порту `8000` в Windows Firewall, если батник запущен от администратора;
- покажет понятную ошибку, если `node` не найден;
- автоматически откроет `http://127.0.0.1:8000`;
- оставит окно открытым, чтобы ты видел логи и не потерял сообщение об ошибке.

## Открытие на разных устройствах

После запуска сайт слушает `0.0.0.0:8000`, но открывать его с другого устройства нужно **не по `0.0.0.0`**, а по **реальному локальному IP** компьютера, где запущен NOMERCY:

```text
http://<твой-local-ip>:8000
```

Сам сервер теперь показывает точные LAN-адреса в консоли при запуске и на стартовом экране сайта.

Если сайт с телефона или другого ПК не открывается, обычно причина в одном из пунктов:

- устройства находятся не в одной Wi-Fi / LAN сети;
- Windows Firewall или другой firewall блокирует входящие подключения к `node.exe` или порту `8000`;
- ты открываешь не тот IP-адрес;
- указываешь публичный IP вместо локального адреса внутри сети.

Если на компьютере сайт открывается, а на телефоне — нет, самый частый сценарий на Windows: запусти `start-nomercy.bat` **от имени администратора** один раз, чтобы батник смог добавить правило для входящих подключений на порт `8000`.

Если ты открываешь сайт по публичному IP, обязательно указывай порт `:8000`, если у тебя не настроен отдельный reverse proxy на `80/443`. При необходимости можно запустить сервер на другом порту так:

```bash
PORT=80 npm start
```

Для быстрой проверки, отвечает ли сервер вообще, доступен health-check:

```text
http://<ip-адрес>:8000/health
```
