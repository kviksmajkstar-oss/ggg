# NOMERCY

NOMERCY — это реально работающий локальный сайт соцсети, который теперь можно запускать **без Python**.

## Что работает

- регистрация и вход пользователей;
- хранение данных в локальном JSON-хранилище;
- редактирование профиля;
- публикация постов в ленту;
- лайки на постах;
- список пользователей;
- личные сообщения между пользователями;
- светлая и тёмная тема интерфейса.

## Технологии

- Node.js без внешних зависимостей;
- встроенный HTTP-сервер;
- HTML / CSS / JavaScript без фреймворков.

## Запуск

### Вариант 1 — через Node.js

```bash
node server.js
```

### Вариант 2 — через npm

```bash
npm start
```

### Вариант 3 — Windows

Запусти файл `start-nomercy.bat`.

После запуска открой:

```text
http://127.0.0.1:8000
```
