# ggg — терминальный мессенджер в стиле Telegram

Локальный TCP-мессенджер на Python (`asyncio`) с базовыми Telegram-подобными возможностями:

- публичные комнаты (групповые чаты);
- личные сообщения (DM);
- список онлайн-пользователей;
- история сообщений по комнатам и личным диалогам.

## Требования

- Python 3.10+
- `pytest` (только для запуска тестов)

## Запуск

### 1) Запуск сервера

```bash
python -m messenger.server --host 127.0.0.1 --port 9000
```

### 2) Подключение клиентов (в отдельных терминалах)

```bash
python -m messenger.client Alice --host 127.0.0.1 --port 9000
python -m messenger.client Bob --host 127.0.0.1 --port 9000
```

## Команды клиента

- `Привет` — отправить сообщение в текущую комнату (по умолчанию `main`);
- `/join team` — войти в комнату `team` и сделать её текущей;
- `/leave team` — выйти из комнаты `team`;
- `/room team сообщение` — отправить сообщение в указанную комнату;
- `/dm Bob привет` — отправить личное сообщение пользователю `Bob`;
- `/users` — показать список онлайн-пользователей;
- `/rooms` — показать список активных комнат;
- `/history room team` — показать историю сообщений комнаты `team`;
- `/history dm Bob` — показать историю личного диалога с `Bob`;
- `/help` — показать справку;
- `/quit` или `/exit` — выйти из клиента.

## Протокол

Сервер и клиент обмениваются `JSON Lines`-пакетами (один JSON-объект на строку).

Примеры клиентских пакетов:

```json
{"action":"join","payload":{"name":"Alice"}}
{"action":"send_room","payload":{"room":"main","text":"Всем привет"}}
{"action":"send_dm","payload":{"to":"Bob","text":"Пойдём в личку"}}
{"action":"history","payload":{"kind":"dm","target":"Bob"}}
```
