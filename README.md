# NOMERCY

NOMERCY — это одностраничный фронтенд-прототип социальной сети, вдохновлённой Facebook по структуре, но с собственной айдентикой: более премиальным визуальным стилем и модулем **Pulse Radar**, который показывает активность и интересы аудитории.

## Что улучшено

- Facebook-подобная структура: верхняя навигация, сторис, composer, лента, shortcuts и контакты.
- Уникальная фишка NOMERCY: блок **Pulse Radar** и **City Radar**.
- Интерактивная лента: создание новых постов, фильтры по категориям и лайки.
- Адаптивная вёрстка для десктопа, планшета и мобильных экранов.

## Запуск

Открой `index.html` в браузере

или запусти локальный сервер:

```bash
python3 -m http.server 8000
```

После этого открой `http://localhost:8000`.
