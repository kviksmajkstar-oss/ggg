# NOMERCY

NOMERCY — это современный фронтенд-прототип социальной сети, вдохновлённой Facebook по структуре, но расширенной новыми сценариями: **live-активность**, **кастомизация профиля** и **свои мини-игры** прямо внутри платформы.

## Что теперь умеет проект

- современная трёхколоночная social-feed архитектура;
- кастомизация профиля через **Profile Lab**: имя, био, тема и статус;
- live-блок с онлайн-метриками и обновлением активности;
- интерактивная лента с публикацией постов, фильтрами и лайками;
- встроенный игровой хаб **NOMERCY Arcade** с двумя мини-играми: `Tap Rush` и `Color Match`.

## Локальный запуск

Открой `index.html` в браузере

или подними локальный сервер:

```bash
python3 -m http.server 8000
```

После запуска открой `http://localhost:8000`.
